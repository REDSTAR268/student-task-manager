# Student Task Manager

A modern and user-friendly task management application built with React and Vite. Designed to help students organize their academic activities, manage tasks, track progress, and stay productive.

## Overview

Student Task Manager provides a centralized workspace where students can manage their daily responsibilities and monitor their productivity through a clean and intuitive interface.

## Features

- **Dashboard:** View an overview of your task management activities.
- **Task Management:** Organize and manage your tasks.
- **Progress Tracking:** Monitor your productivity and task progress.
- **Settings:** Customize application preferences.
- **Contact:** Access the contact page.
- **Responsive Design:** Enjoy a user-friendly interface across different screen sizes.

## Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/REDSTAR268/student-task-manager.git
```

### 2. Navigate into the project folder

```bash
cd student-task-manager
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.
